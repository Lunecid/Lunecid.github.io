이 사이트(<https://lunecid.github.io>)는 백성은이 개인 포트폴리오로 운영하는 정적 웹사이트입니다. 회원가입, 로그인, 댓글 기능이 없고 방문자가 이름이나 연락처를 입력하는 곳도 없습니다. 플레이 로그에는 사이트 주인만 쓰는 연동 관리 화면이 있습니다. 주인이 GitHub·Steam으로 로그인하고 게임 계정 ID를 저장할 때, 그 값과 로그인 정보는 주인의 브라우저에서 Cloudflare Worker(중계 서버)를 거쳐 GitHub와 Steam으로만 갑니다. 방문자의 브라우저는 이 중계 서버에 접속하지 않습니다.

## 방문 통계

방문 수를 세려고 [GoatCounter](https://www.goatcounter.com)를 씁니다. GoatCounter는 쿠키, localStorage 같은 브라우저 저장 공간을 쓰지 않습니다.

GoatCounter가 저장하는 항목은 다음과 같습니다. 모두 날짜·시간 단위로 합산한 수치로만 남고, 항목끼리 서로 연결되지 않습니다.

- 방문한 페이지 주소와 유입 경로(이전 페이지 주소)
- 브라우저와 운영체제의 이름·버전
- 화면 너비
- IP 주소로 추정한 국가(미국·러시아·중국은 지역까지)

GoatCounter는 IP 주소, User-Agent 원문, 방문자를 구별하는 ID를 저장하지 않습니다. 같은 사람이 새로고침한 것을 한 번으로 세려고 사이트·IP·User-Agent 조합을 서버 메모리에 최대 8시간 두지만, 데이터베이스에는 기록하지 않습니다. 이 사이트는 개별 방문 기록을 남기는 선택 기능을 켜지 않습니다.

합산된 통계는 [방문 통계](/stats/) 페이지에 공개합니다. GoatCounter 데이터는 핀란드와 독일에 있는 Hetzner 서버에 저장됩니다. 자세한 내용은 [GoatCounter 개인정보 처리방침](https://www.goatcounter.com/privacy)을 참고하세요.

## 호스팅

이 사이트는 GitHub Pages로 제공됩니다. GitHub은 보안을 위해 GitHub Pages 사이트 방문자의 IP 주소를 기록하고 보관합니다. 자세한 내용은 [GitHub 개인정보 처리방침](https://docs.github.com/ko/site-policy/privacy-policies/github-general-privacy-statement)을 참고하세요.

## 브라우저에 저장하는 설정

다음 설정은 방문자 브라우저의 저장 공간(localStorage, sessionStorage)에만 저장하고 서버로 보내지 않습니다. 브라우저의 사이트 데이터를 지우면 함께 지워집니다.

- 소리 켜기·끄기, 모션 끄기
- 사이트 업적 달성 기록
- 업적을 위해 둘러본 메뉴(연구·프로젝트·기록·플레이 로그)와 언어
- 시작 화면 연출(CRT 인트로)과 첫 화면 문구 등장을 이번 방문에서 이미 봤는지 여부
- 배경음악을 이어 듣기 위한 재생 위치(sessionStorage, 창을 닫으면 사라지고 30분이 지나면 쓰지 않음)
- 마지막으로 고른 포트폴리오 버전(게임·일반)

## 게임 계정 데이터

플레이 로그의 계정 카드는 사이트 주인 자신의 게임 계정만 보여 줍니다. 방문자의 계정 데이터는 모으지 않습니다.

- 출처: 원신·젠레스 존 제로는 Enka.Network, Steam은 Steam Web API에서 받습니다. 리그 오브 레전드·TFT는 op.gg·lolchess.gg로 가는 링크만 두고 데이터를 받지 않습니다. 이 링크를 누르면 그 사이트의 개인정보 처리방침이 적용됩니다.
- 저장하는 항목: 카드에 보이는 공개 프로필 정보만 저장합니다. Steam은 프로필 링크에 쓰는 SteamID, 닉네임, 아바타, 레벨, 그리고 주인이 켠 경우에만 보유 게임 수, 플레이 시간, 주인이 거른 뒤의 상위 게임을 저장합니다. 실명, 국가, 계정 생성일, 그룹은 저장하지 않습니다.
- 저장 위치: 사이트를 빌드할 때 GitHub Actions에서 만들고 GitHub Pages로 제공합니다(GitHub, Inc., 미국). 저장소에는 커밋하지 않습니다.
- 보관 기간: 계정 데이터 아티팩트는 1일, 빌드 화면 사진 아티팩트는 최대 14일, 테스트 실패 보고서는 7일 동안 남고, 빌드 이미지 캐시는 캐시가 밀려날 때까지 남습니다. 주인의 게임 계정 ID와 닉네임은 공개된 빌드 실행 기록에 나타나며 저장소의 기록 보존 기간 동안 남습니다.
- 갱신: 매일 03:30(한국 시간)과 주인이 사이트를 다시 빌드할 때 갱신합니다. 7일 동안 갱신되지 않으면 카드를 숨깁니다.
- 방문자의 브라우저는 게임 서비스에 접속하지 않습니다. 카드의 이미지는 이 사이트에서 직접 제공합니다.
- Steam 데이터는 Steam Web API 이용약관에 따라 있는 그대로(<span lang="en">as is</span>) 제공하며 정확성을 보증하지 않습니다.

던전앤파이터는 연동하지 않습니다.

방문자의 게임 계정 정보는 어떤 경우에도 수집하지 않습니다.

## 외부 서비스와 링크

- 글꼴, 배경음악, 이미지, 방문 통계 스크립트는 모두 이 사이트에서 직접 제공합니다. 방문 기록은 GoatCounter 서버로만 전송됩니다.
- 방문 통계 페이지의 수치는 사이트를 빌드할 때 GoatCounter API(읽기 전용 키)에서 받아 둔 합산값입니다. 누적 방문 수 하나만 방문자의 브라우저가 GoatCounter 공개 카운터에서 직접 불러옵니다.
- GitHub 저장소 목록과 기여 그래프는 사이트를 빌드할 때 GitHub API에서 받아 둡니다. 방문자의 브라우저는 GitHub API나 중계 서버를 호출하지 않습니다.
- GitHub, IEEE Xplore 같은 외부 링크를 누르면 그 사이트의 개인정보 처리방침이 적용됩니다.
- 플레이 로그의 바깥 전적 링크(op.gg·lolchess.gg)는 리퍼러(이전 페이지 주소)를 보내지 않습니다.
- 사이트 주인만 쓰는 연동 관리는 Cloudflare, Inc.의 Workers 중계 서버를 씁니다. Cloudflare는 이 처리에서 주인을 대신해 요청을 전달하는 처리자입니다. Cloudflare는 전 세계 네트워크에서 요청을 처리하며, 어느 위치에서 처리되는지는 주인의 접속 위치에 따릅니다.
  - 중계 서버를 지나가는 것: 주인의 GitHub 로그인 정보(GitHub가 발급한 접근 토큰. 중계 서버 밖에서는 암호화된 상태로만 있고 최대 60분 뒤 쓸 수 없으며, 로그아웃하면 GitHub에서 승인이 지워집니다), 주인이 저장하는 게임 계정 ID와 닉네임, 주인의 Steam 로그인 확인 정보(Steam이 서명한 응답), 주인의 SteamID와 Steam 프로필 이름·공개 여부.
  - 중계 서버는 이 값을 저장하지 않고, 요청 기록(호출 로그)을 끄고 운영합니다. Cloudflare가 서비스 운영을 위해 따로 남기는 기록은 Cloudflare의 방침을 따릅니다. 자세한 내용은 [Cloudflare 개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)을 참고하세요.
  - 로그인할 때 주인의 브라우저에 중계 서버 주소의 쿠키 하나(로그인 확인용)가 생깁니다. 로그인이 사이트로 돌아올 때 지워지고, 돌아오지 않으면 늦어도 10분 뒤 만료됩니다. 이 사이트 주소에는 새 쿠키나 저장소 항목이 없습니다.
